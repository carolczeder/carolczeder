# Olá, sou a Carol! 👋

Analista de Dados e Automação. Transformo dados brutos em informação confiável e elimino processos manuais com automação.
Pós-graduada em Inteligência Artificial e Machine Learning, cursando Ciência da Computação.

---

### ⚙️ O que eu faço

- 🧹 Trato e limpo grandes volumes de dados, padronizando e protegendo informações sensíveis
- 🔍 Faço consultas e análises em SQL no BigQuery para gerar insights e apoiar decisões de negócio
- 📊 Crio e mantenho dashboards no Looker Studio conectados a dados tratados
- 🤖 Construo automações com n8n, Make, Google Apps Script e Python
- 🔌 Integro sistemas via APIs REST e Webhooks (ex.: ActiveCampaign, Pipedrive)
- 🏗️ Estruturo data warehouse e pipelines de ingestão e transformação no BigQuery (GCP)

---

### 🚀 Projetos em destaque

**Weather Data Pipeline**
Pipeline de dados de ponta a ponta, da coleta ao dado pronto para análise, com arquitetura medallion no BigQuery.

**AromaSearch**
Sistema de recomendação de perfumes com RAG: embeddings, busca vetorial por similaridade e integração com LLM.
